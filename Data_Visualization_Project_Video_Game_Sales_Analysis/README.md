# 🎮 Data Visualization Project: Video Game Sales Analysis

An end-to-end data visualization project that analyzes global video game sales to uncover trends in gaming platforms, genres, publishers, critic ratings, and release years. The project includes data cleaning, exploratory data analysis (EDA), interactive visualizations, and a Streamlit dashboard.

---

## 📌 Project Overview

This project explores the **Video Game Sales Dataset** using Python and modern data visualization libraries. The objective is to extract meaningful insights from the dataset and present them through interactive charts and dashboards.

The project demonstrates a complete data analysis workflow:

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Visualization
- Interactive Dashboard Development
- GitHub Project Documentation

---

## 🎯 Objectives

- Clean and preprocess the dataset.
- Perform exploratory data analysis (EDA).
- Identify top-performing gaming platforms and genres.
- Analyze critic and user review patterns.
- Explore sales trends over time.
- Build an interactive Streamlit dashboard for data exploration.

---

## 📊 Dataset

**Dataset:** Video Game Sales Dataset

The dataset contains information about video games, including:

- Game Name
- Platform
- Genre
- Publisher
- Release Year
- Regional Sales

- Critic Score
- User Score

## 📈 Exploratory Data Analysis

The notebook answers several business questions, including:

1. Which gaming platforms generated the highest global sales?
2. Which genres are the most popular worldwide?
3. Which publishers have the highest total sales?
4. How have global game sales changed over time?
5. Do higher critic scores relate to higher global sales?
6. Which platform–genre combinations perform best?
7. Which publishers dominate the market?
8. How do ESRB ratings compare in average sales?
9. What are the highest-selling games?
10. What key insights can be derived from the dataset?

Each visualization includes a brief explanation and insight.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Data_Visualization_Project_Video_Game_Sales_Analysis.git
```

Navigate to the project folder:

```bash
cd Data_Visualization_Project_Video_Game_Sales_Analysis
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit dashboard:

```bash
streamlit run app.py
```

## 📌 Key Insights

- PlayStation 2 generated the highest global sales.
- Action games dominated worldwide sales.
- Nintendo and Electronic Arts were among the leading publishers.
- Higher critic scores generally corresponded with stronger sales.
- Global game sales peaked around 2008–2009 before declining.
